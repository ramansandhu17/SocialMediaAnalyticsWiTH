# Social Media Analytics (Volunteer Project for WiTH Data)

This open-source project analyzes social media data from LinkedIn and Facebook for **WiTH Data**, a volunteer-based initiative. The goal is to extract actionable insights on post performance and engagement trends — showcasing real-world analytics and data science skills using open tools.

---

## Project Objectives

- Track and visualize engagement trends across platforms
- Identify top-performing post formats and themes
- Build a predictive model for post engagement
- Run A/B tests to experiment with content strategies
- Create an interactive dashboard for stakeholders

---

## Tools & Technologies

- **Python** (Pandas, Seaborn, Scikit-learn)
- **Tableau** (for interactive dashboarding)
- **Streamlit** (optional for modeling demo)
- **GitHub** (open-source workflow)
- **Jupyter Notebooks**
